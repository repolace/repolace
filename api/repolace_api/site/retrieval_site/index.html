What is this?

repolace is a system that tries to fix a bug report by editing a software project’s code. A real project holds thousands of functions, so before it can edit anything it has to find the right place with a search step. This page measures how well that search step works, and whether changing how it prepares text makes it better.

None of the changes we tried clearly beat today’s default at finding the right code.
