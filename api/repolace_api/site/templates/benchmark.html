Method and limits

  • What passed means

    Every test the real fix added passes and no test that passed before fails, run in a rootless container against the code with the agent's edit.

  • Public issues

    SWE-bench Verified is public. A model may have seen these issues or their fixes. The figure may be optimistic for repositories no model has seen; we have not measured those yet.

  • Not measured yet

    Opening a real pull request, other models, other languages (indexing is Python only), and private repositories.

  • Cost

    Model fees only, at the provider's listed rates. Sandbox compute, storage and our own overhead are not in these figures.
