What counts as a task

A fix that opens a pull request
Uses one task.
An attempt that finds no fix
Uses one task, because the model and the sandbox time were spent. You still get the plan and the test results to read.
A failure on our side
Uses nothing. If repolace or its model provider breaks mid-task, the task is not counted.
A runaway task
Is stopped, not billed on. Each task has a fixed model-spend limit of ${{ '%.2f'|format(facts.cap_usd) }}, a call limit and a time limit.

Why these numbers

In our first measurement a task cost about ${{ '%.2f'|format(facts.cost_mean) }} in model fees on average, and {{ '%.0f'|format(facts.rate) }}% of runs passed ({{ '%.0f'|format(facts.ci_low) }} to {{ '%.0f'|format(facts.ci_high) }}% interval, on public benchmark issues). Prices are set to cover the model and sandbox cost of a task and to keep the service running, while the success rate on your own repository may differ from the benchmark.
