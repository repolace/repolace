# Benchmark report (served at /benchmark/)

A copy of `BENCHMARK/site/` from the `feat/benchmark-site` branch (worktree `../repolace-site`), the static page
that used to be deployed as the Cloudflare Worker `repolace-benchmark`. Only the files the page loads are here; the
render caches, temp images, `serve.py` and the video build files are not.

Changes made so it runs under the public site's Content-Security-Policy (`script-src 'self'`, `style-src 'self'`,
no remote origin) and follows the official headline:

- `index.html`: the inline theme script moved to `js/theme-init.js`; D3 is `js/vendor/d3.min.js` instead of cdnjs;
  the description and headline say 29 of 54 (53.7%, the official sweep-4 figure).
- `js/core.js`: `el()` sets `style` through `style.cssText` (allowed) instead of `setAttribute("style")` (blocked);
  `js/budget.js`: the legend swatch is built with `el()`; `js/main.js`: the D3 credit line.
- `js/hero.js`: the hero reads `runs["sweep-4"]`, and its note says the 35/54 figure is a hand-stated substitution used
  as the comparisons' baseline.
- `js/vendor/d3.min.js` is **D3 7.8.5**, copied from CPython 3.15's `profiling/sampling/_vendor/d3/7.8.5/` (ISC licence),
  sha256 `d6b03aefc9f6c44c7bc78713679c78c295028fa914319119e5cc4b4954855b1c`. The page was written against 7.9.0;
  swap in 7.9.0 (cdnjs/npm) if a chart misbehaves.

`data/report.json` is generated by the benchmark branch's build; refresh it by copying the new file in.
